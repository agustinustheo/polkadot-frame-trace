# Jaeger

Jaeger 2.22.0 in one container: the lightest way to look at a polkadot-frame-trace trace.

| Port | What |
| --- | --- |
| 16686 | Jaeger web page |
| 4318 | OTLP/HTTP, where polkadot-frame-trace sends traces |

[Send traces to Jaeger](../../docs/guides/send-traces.md#jaeger) shows how to start it, send a trace and stop it.
